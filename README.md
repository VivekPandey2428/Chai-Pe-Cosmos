# Chai Pe Cosmos

*Science, Hinglish mein. Ek chai ke saath.* ☕🪐

Funny 3D animated YouTube Shorts that make space and physics easy, with two recurring characters:
**the guy** (the mascot, always with a kulhad of chai) and **Hawaldar sahab** (a traffic cop with a radar gun).

- **Start here:** [`SERIES.md`](SERIES.md), the series bible: characters, voices, look, story formula, fact rules,
  growth playbook, pipeline and episode log.
- **Make the next episode:** open this repository in Claude Code and type `/new-episode <topic>`
  ([`.claude/skills/new-episode/SKILL.md`](.claude/skills/new-episode/SKILL.md)).
- **Episode 1, "Chai Peete Hue Challan Kat Gaya!":** `renders/challan_9x16_1080x1920.mp4`; thumbnails in `thumbs/out/`.
- **Brand:** `brand/avatar-800x800.png`, `brand/cover-2560x1440.png`.

Built with [HyperFrames](https://hyperframes.heygen.com), three.js and ElevenLabs. Setup on a fresh machine:
`npm install`, `npx skills add heygen-com/hyperframes`, and FFmpeg.
